# Github_Experimentation
## TD2 : Langages de balisage léger V 1.3.0


Ci-dessous se trouve notre travail réalisé sur une page __wiki__ GitHub :

__[PAGE WIKI](https://github.com/Itsnotjalan/Github_Experimentation/wiki/Wiki_Mikr%C3%B2s#sommaire)__

Pour ce travail, nous avons utilisé la section __Wiki__ de GitHub et nous avons 
créé plusieurs sections principalement basée sur l'entreprise apple.
Nos sources viennent de wikipedia.

Pour la création de ce wiki, nous avons suivi le plus d'étapes possibles
- [x] Créer le wiki
- [x] Créer une page Wiki_mikos qui présente un sommaire
- [x] créer une section Apple et faire son contenu
- [x] créer une section Face-Id et faire son contenu
- [x] créer une section Iphone et faire son contenu
- [ ] créer encore d'autres section pour développer le wiki (+ tard)

C'est un sujet qui nous tenait a coeur car Apple est une entreprise mondialement connue.
